# 🌸 Pink Pomodoro Timer

귀엽고 화사한 파스텔 톤 테마로 집중력을 높여주는 **바닐라 자바스크립트 뽀모도로 타이머**입니다.

## ✨ 주요 기능
- **집중 및 휴식 모드**: 집중(25분), 짧은 휴식(5분), 긴 휴식(15분) 모드 제공
- **테마 변경 기능**: 취향에 따라 선택할 수 있는 파스텔 컬러 테마 (핑크, 라벤더, 피치)
- **직관적인 UI/UX**: 깔끔하고 부드러운 애니메이션과 반응형 디자인

## 🛠️ 사용 기술
- HTML5
- CSS3 (CSS Variables, Flexbox)
- Vanilla JavaScript (DOM API, setInterval)
