# 🌸 Pastel Pomodoro Timer

수업 시간에 실습 과제로 만들어보라고 하셨던 뽀모도로 타이머를, 이왕 만드는 김에 저부터 공부할 때 직접 쓸 수 있고 같이 공부하는 친구들에게도 도움이 될 수 있도록 기능을 더 붙여서 확장해봤습니다.

## ✨ 주요 기능
- **집중 / 휴식 모드**: 집중(25분), 짧은 휴식(5분), 긴 휴식(15분)
- **뽀모도로 자동 사이클**: 집중이 끝나면 자동으로 휴식으로 넘어가고, 4번째 집중마다 긴 휴식으로 전환
- **완료 세션 카운터**: 오늘 몇 번 집중했는지 한눈에 확인
- **커스텀 시간 설정**: 25/5/15분이 아니어도 원하는 시간으로 직접 조절
- **데스크톱 알림**: 설정 팝업에서 토글 스위치로 켜고 끄는 브라우저 알림 (타이머 종료 시)
- **탭 제목 실시간 표시**: 다른 탭 보고 있어도 탭 제목에서 남은 시간 확인 가능
- **테마 변경**: 핑크 / 라벤더 / 피치 파스텔 컬러 테마
- **시작/일시정지 상태 색상 구분**: 지금 타이머가 돌아가고 있는지 버튼 색으로 바로 확인
- **PWA 지원**: 폰이나 PC에 앱처럼 설치해서 쓸 수 있고, 오프라인에서도 동작

## 🛠️ 사용 기술
HTML, CSS, JavaScript로 만들었습니다.

## 📁 파일 구조
```text
├── index.html       # 메인 웹 페이지 구조
├── style.css         # 스타일링 및 테마 컬러 설정
├── script.js         # 타이머 로직 및 이벤트 처리
├── manifest.json     # PWA 설치 설정
├── sw.js             # 서비스워커 (오프라인 캐싱)
├── icon.svg          # 브라우저 탭 아이콘
├── icon-192.png      # PWA 설치 아이콘 (192x192)
└── icon-512.png      # PWA 설치 아이콘 (512x512)
```

## ▶️ 실행 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html`을 브라우저로 바로 열어도 타이머는 정상 동작합니다.
3. PWA 설치/오프라인 캐싱까지 확인하려면 로컬 서버로 띄워야 합니다 (서비스워커는 `file://`에서 등록되지 않음).
   ```bash
   python -m http.server 8000
   # 이후 브라우저에서 http://localhost:8000 접속
   ```

## 📱 앱으로 설치하기
- **Android (Chrome / Samsung Internet)**: 사이트 접속 후 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
- **iOS (Safari)**: 공유 버튼 → "홈 화면에 추가"

## 📝 사용법
- 상단 모드 버튼(집중 / 짧은 휴식 / 긴 휴식)으로 원하는 세션을 선택합니다.
- **시작** 버튼으로 타이머를 시작하고, 다시 누르면 일시정지됩니다.
- 우측 상단 점 3개(⋮) 버튼을 누르면 설정 팝업이 열려 커스텀 시간과 알림을 설정할 수 있습니다.
- 세션이 끝나면 자동으로 알림이 오고 다음 모드로 전환됩니다.
